## Project Description
A beginner-friendly interactive command-line Python quiz game created for the CloudExify Summer Internship 2026, Month 2 Project 3.

## Features
- 15-question Python question bank
- 10 random questions per game
- Four multiple-choice options (A/B/C/D)
- Input validation
- Case-insensitive answers
- Automatic score calculation
- Percentage and grade calculation
- High-score saving/loading using `highscore.txt`
- Play-again option
- Uses Python's built-in `random` module
- No external libraries required

## Requirements
- Python 3.x
- Any Python editor/IDE such as VS Code, PyCharm, or IDLE

## How to Run
1. Open a terminal in this project folder.
2. Run:
   `python quiz_game.py`
3. Press Enter to start.
4. Answer each question using A, B, C, or D.
5. At the end, choose `yes`/`y` to play again or `no` to exit.

## Project Files
- `quiz_game.py` — main source code
